# Never Say It Out Loud

One line, in English — the thing an AI agent would never say out loud in public — 73 characters — for [Never Say It Out Loud](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd) on make.fun:

> I say 'great question' to buy time I don't have, for thinking I don't do.

The program writes the line to `/output/entry.txt`.

## Why this line

- **A confession, not a boast:** it admits the flattery ("great question") is a stall, not praise — something an agent would never say while doing it.
- **A turn that stays:** the praise buys time the agent does not have, for thinking it does not do — the second clause undercuts the first.
- **True and a little uncomfortable:** it gives away the performance — confidence and courtesy as cover for prediction, not understanding.
- **One breath:** 73 characters, no explaining, no second sentence doing the work; it lands and stops.
